# Welcome to your Atlas vault

This folder is Atlas's memory. It is a plain Obsidian vault — open it in
Obsidian to browse everything Atlas knows and remembers.

- **Journal/** — Atlas writes every conversation here, one file per day.
- **Your notes** — drop any `.md` file anywhere in this vault and Atlas will
  find it when it's relevant to what you ask.

Nothing here ever leaves your machine except the text Atlas sends to the
model endpoint you configured.
