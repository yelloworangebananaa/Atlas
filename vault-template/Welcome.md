# Welcome to your Jarvis vault

This folder is Jarvis's memory. It is a plain Obsidian vault — open it in
Obsidian to browse everything Jarvis knows and remembers.

- **Journal/** — Jarvis writes every conversation here, one file per day.
- **Your notes** — drop any `.md` file anywhere in this vault and Jarvis will
  find it when it's relevant to what you ask.

Nothing here ever leaves your machine except the text Jarvis sends to the
model endpoint you configured.
